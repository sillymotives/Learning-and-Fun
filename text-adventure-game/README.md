# Text Adventure Game

## Overview
This is a simple text adventure game that allows players to explore a fictional world, interact with characters, and solve puzzles. The game is played through a command-line interface (CLI) and focuses on storytelling and player choices.

## How to Play
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies using the command:
   ```
   pip install -r requirements.txt
   ```
4. Run the game using the command:
   ```
   python main.py
   ```
5. Follow the on-screen instructions to navigate through the game world and make choices.

## Installation Instructions
To set up the project, ensure you have Python installed on your machine. Then, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Change into the project directory:
   ```
   cd text-adventure-game
   ```
3. Install the required packages:
   ```
   pip install -r requirements.txt
   ```
